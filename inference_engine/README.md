| Task            | Performance        | Efficient            |
| --------------- | ------------------ | -------------------- |

| **Translation** | MADLAD-400 3B      | NLLB-200 1.3B        |
| **TTS**         | **Qwen3-TTS 1.7B** | **OuteTTS 0.2 500M** |
